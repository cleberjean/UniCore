# UniCore
Turn sleep all extra (AP) cores from processor, in Real Mode DOS, leaving only BSP core active.

Allow activate maximum turbo boost frequency/multiplier from Intel processors.

</br>

Tested on:
---------
✓ Intel 8088 (DOSBox-X)*

✓ Intel 80286 (DOSBox-X)*

✓ Intel 80386 (DOSBox-X)*

✓ Intel 80486 (DOSBox-X)*

✓ Pentium (DOSBox-X)*

✓ Pentium II (DOSBox-X)*

✓ Pentium III (DOSBox-X)*

✓ Pentium 4 HT (hardware)

✓ Core 2 Duo/Quad (hardware)

✓ Xeon E3-1275 V2 (hardware with UMBPCI.SYS)

✓ Core i7-8700 (hardware)

(*) On DOSBox(-X) detects the emulation environment and aborts.

Additional tests:
----------------
✓ MS-DOS 6.22

✓ EMM386.EXE (Protected Mode)

✓ UMBPCI.SYS (LOADHIGH detection)

✓ Windows 3.1 Standard/Enhanced Mode

</br>

**DO NOT load with LOADHIGH command.**
